# Spec-Driven Development

Project changes are tracked under `specs/` before implementation. Each change folder contains:

- `spec.md`: user problem, scope, requirements, and acceptance criteria.
- `plan.md`: design decisions and implementation sequence.
- `tasks.md`: checklist updated as work progresses, including verification results.

Keep `Requerment.md` as the product-level requirements source. Update the relevant specification and task status whenever behavior changes.

The Alt + selection meaning feature is tracked in `007-alt-selection-meaning/`.
Production startup and deployment documentation is tracked in `008-production-docs/`.
The Chrome MV3 implementation and release packaging are tracked in `009-chrome-native/`.
The now-superseded Chrome-only branch scope is recorded in `010-chrome-only-branch/`.
The separate Chrome and Firefox source trees are tracked in `011-dual-browser-layout/`.
The current setup, testing, troubleshooting, privacy, and store release instructions are in the root `README.md` and are maintained under `012-user-documentation/`.
